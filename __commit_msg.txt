fix: add offline_access scope to Figma OAuth (enables refresh token, fixes re-oauth on every reload)

Root cause: Figma OAuth auth URL only requested 'file_content:read' scope.
Without 'offline_access', Figma's token exchange NEVER returns a refresh_token.
So tokenData.refreshToken was always '' (empty), and getValidToken() could
never refresh — returning null once the 1-hour access token expired.

Now with 'offline_access' scoped, Figma returns a refresh_token valid ~90d,
and getValidToken() can silently refresh on every page load.

Note: existing tokens have no refresh token. Users must re-auth Figma ONCE
after deploy to obtain a token with refresh_token. After that, no more
reconnects.
