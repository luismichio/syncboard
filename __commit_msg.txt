fix: remove /api/figma/verify startup check (OAuth tokens rejected by /v1/me)

Figma's /v1/me endpoint only accepts Personal Access Tokens, not OAuth
tokens. So the verify endpoint returned 401 for every valid OAuth token,
causing the plugin to clear the Figma connection on every reload.

Removed the verify call from useAuthTokens.ts. Server-side token
revocation is now caught at sync time (Figami API 401 → error handler).
