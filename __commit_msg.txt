fix: batch limit counts unique exports, not total widgets

The batch limit of 3 now applies to unique
(fileKey, nodeId, format, scale, platform) groups — i.e., distinct
Figma/Penpot exports. Widget copies of the same frame share the render
cache and are NOT counted against the limit. With syncAllCopies enabled,
all copies of the first 3 frames sync without extra export slots.

Also removed silent truncation — the sync function now throws an error
if called with >3 unique groups (defense-in-depth; the UI already
prevents this via the disabled button + warning banner).
