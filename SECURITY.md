# Security Policy

## Supported Versions

We actively monitor and patch security vulnerabilities in SyncBoard. Security updates are applied to the following versions:

| Version | Supported |
| ------- | --------- |
| < 0.1.x | ❌ No      |
| 0.1.x   |  Yes     |

Please ensure you are running the latest version of SyncBoard to receive active security updates.

---

## Reporting a Vulnerability

**Do not open public GitHub issues for security vulnerabilities.**

If you discover a security vulnerability or exploit in SyncBoard, please report it to us privately via email at **security-syncboard@luiskobayashi.com**.

When reporting, please include:
1. A detailed description of the vulnerability.
2. Step-by-step instructions or proof-of-concept (PoC) to reproduce the issue.
3. The potential impact of the vulnerability.

We will acknowledge your report within 48 hours and work with you to analyze, patch, and release a fix. We ask that you keep the details confidential until we have had reasonable time to secure our users' environments and release a patch.

Thank you for helping keep SyncBoard secure!
