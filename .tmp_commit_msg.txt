fix(figjam): per-instance selection parity — cards count c=all, sync updates only selected

Two parity fixes after "Sync(0) with nothing selected" landed:
- Cards: trackedToSynced no longer dedupes by key - every selected INSTANCE
  becomes a card (SyncTab group shows "xN" for duplicates); selecting 3
  duplicates of one frame shows 3 (group x3), two different frames show 2.
- Sync targeting: figjam-place payload now carries nodeIds = the selected
  instance ids; the plugin updates ONLY those instances. Sync loop renders
  once per unique frame key but applies to exactly the selected node IDs -
  selecting one duplicate and syncing no longer syncs its sisters.
